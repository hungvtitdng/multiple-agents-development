# Ví dụ KB theo stack: Rails + JS/TS

Nội dung cụ thể cho Rails và frontend JS/TS, tách ra khỏi skill chung của plugin. Plugin không dùng thư mục này.

| File ví dụ | Chép vào dự án |
|---|---|
| `security-review.md` | `docs/security/review-patterns.md` |
| `migration-safety.md` | `docs/database/migration-rules.md` |
| `test-automation.md` | `docs/testing/automation-guide.md` |
| `code-review.md` (mục "Grep gợi ý") | `docs/engineering/review-checklist.md`, mục "Mẫu tìm lỗi theo stack" |

Khi chép: giữ phần đúng với dự án, thêm ví dụ `file:dòng` từ code thật, gắn nhãn và `verified-at: <commit>`. Scout của `/agent-team:kb` cũng tự viết nháp các file này từ code.
