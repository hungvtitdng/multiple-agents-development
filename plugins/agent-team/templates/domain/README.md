# Knowledge base (domain)

Nơi gom kiến thức nghiệp vụ qua các task. Mọi agent **đọc** trước khi làm. Chỉ **business-analyst** (và Lead) được ghi.

- `glossary.md`: thuật ngữ nghiệp vụ
- `business-rules.md`: quy tắc nghiệp vụ đã chốt
- `decisions.md`: quyết định đã chốt, lý do, task nguồn

Task xong (S6): BA cập nhật, Requirement Reviewer duyệt. Mỗi mục ghi task nguồn `docs/agent-tasks/<task-id>`.
